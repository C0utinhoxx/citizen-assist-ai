# Teste com usuários — materiais

**Status:** materiais prontos; execução pendente.

Esta pasta contém:

- [`protocolo.md`](protocolo.md) — objetivo, ética, perfil, roteiro, métricas e critérios.
- [`protocolo_rapido.md`](protocolo_rapido.md) — versão reduzida: 5 pessoas, 6 tarefas, 15–20 min por pessoa.
- [`formulario.md`](formulario.md) — formulário imprimível por participante anônimo, com o questionário de 5 perguntas.
- [`planilha.csv`](planilha.csv) — planilha para consolidar os resultados das tarefas.
- [`questionario.csv`](questionario.csv) — planilha para o questionário de facilidade de uso (5 perguntas).
- [`relatorio.md`](relatorio.md) — modelo do relatório final, com as tabelas a preencher.

## Regras de privacidade

- Nada de nomes, CPF, RG, CNH, título, telefone, e-mail, endereço ou idade.
- Use apenas códigos anônimos: P01, P02, ...
- Consentimento verbal; registrar apenas sim/não.
- Não gravar áudio/vídeo.
- Revisar comentários antes de salvar.

## Como executar

1. Recrutar pelo menos 5 pessoas externas ao grupo.
2. Abrir `python3 main_agente.py`.
3. Seguir o roteiro de `protocolo.md`.
4. Preencher um `formulario.md` por participante.
5. Transferir os dados para `planilha.csv`.
6. Calcular acerto, tempo médio e facilidade média.
7. Anexar o resumo à documentação única.

## O que não fazer

- Não inventar participantes ou resultados.
- Não testar com integrantes do grupo.
- Não ajudar o participante a responder.
- Não publicar a planilha com comentários identificáveis.

Enquanto a execução não acontecer, o teste permanece **pendente**.
